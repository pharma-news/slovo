# «Слово» — игра у экрана по «Словарю языка Пушкина»

Экран поделён на **четыре части**. Печать каждой части запускается **отдельно**
кнопкой со значком — как будто печатает пишущая машинка (можно читать вслух
синхронно с экраном). **Непонятное слово выделено**: заглавные буквы, цвет,
жирный, пунктирное подчёркивание и лёгкое мерцание.

На заднем плане — тихий мир: светило в небе, облака, птицы, дали, лес, поле.
Он еле заметен и чуть заметно дышит: облака идут, колосья качаются, птицы
машут крыльями, а картинка слегка следует за курсором.

Никакого меню на экране нет: только две кнопки в углу каждой четверти и
кружок тем посередине. Ответы сразу **не показываются** — дети ищут
выделенные слова в «Словаре языка Пушкина», кто быстрее. Пояснения можно
вывести на экран (по одной четверти или сразу во всех), а можно и не выводить.

Ничего устанавливать не нужно: это папка с файлами, интернет не требуется.

## Как запустить

- двойной клик по файлу `index.html`, или
- открыть в браузере: https://pharma-news.github.io/slovo/

Дальше — двойной клик мышью (или клавиша `F`), чтобы выйти на весь экран.
Экран пустой: текст начинает печататься **только после нажатия `▶`**.

## Кнопки в углу каждой четверти

| Значок | Где | Что делает |
|--------|-----|-----------|
| `▶` | внизу слева | начать печать **этой** четверти (или напечатать её заново). Остальные три при этом не трогаются |
| `?` | внизу справа | показать или спрятать пояснение **только к этому слову** — удобно, когда одна команда уже справилась, а остальные ещё ищут |

Кнопки полупрозрачные, становятся яркими, когда наводишь мышь на четверть.
Клик по самой четверти во время печати допечатывает её целиком — если вы
читаете быстрее экрана.

Посередине экрана — **кружок тем**: 🌙 тёмная → ☀️ белая → 📜 бежевая
(«под старую бумагу»). Выбор запоминается в браузере.

## Клавиши (на экране их нет — это запас для учителя)

| Клавиша | Что делает |
|---------|-----------|
| `1` `2` `3` `4` | начать печать соответствующей четверти (то же, что `▶`) |
| `Пробел` | пауза / продолжить |
| `R` | очистить весь экран (снова ни одна четверть не печатается) |
| `V` | скорость: **медленно** (по умолчанию) · средне · быстро |
| `PageDown` или `→` | допечатать текущую четверть целиком |
| `E` | пояснения сразу во всех четырёх (повторно — скрыть) |
| `P` | спрятать / показать подписи «А. Пушкин. …» под отрывками |
| `T` | тема оформления |
| `F` или двойной клик | на весь экран |

## Любой экран: как это подгоняется

Кегль каждой четверти подбирается **по факту**: текст измеряется уже
напечатанным и уменьшается до тех пор, пока не перестанет выходить за свою
четверть и не начнёт наезжать на кнопки. Перерасчёт происходит при любом
изменении размера окна, при повороте устройства и после того, как догрузятся
шрифты. Поэтому:

- на **1920×1080** — ~42 px, на **1600×900** — ~35 px, на **1366×768** — ~30 px;
- на **планшете в портрете** и на **телефоне** четверти складываются в столбик,
  межстрочный интервал уплотняется, а подпись «А. Пушкин…» скрывается, когда
  для неё не хватает места;
- на очень маленьком экране (например 320×568) в крайнем случае четверть
  можно пролистать пальцем — текст не обрезается;
- стихотворные строки никогда не переносятся: строка остаётся строкой.

Проверено на 1366×768, 1600×900, 1920×1080, 2560×1440, 1280×500, 1024×768,
768×1024, 844×390, 390×844, 360×640, 320×568 — ничего не вылезает.

Если в системе включена настройка «уменьшить движение», все анимации
(облака, птицы, колосья, мерцание, курсор) выключаются — остаётся статичная
картинка.

## Как менять отрывки и слова

Всё в файле `data.js` — можно править в любом текстовом редакторе и
перезагрузить страницу. Слово‑загадка в тексте выделяется звёздочками:
`*СИКУРСУ*`. Поля у каждого отрывка:

```js
{
  text:   'строчки\nчерез \n',   // *звёздочками* — загаданное слово
  answer: 'сику́рс',              // словарная статья (для карточки)
  gloss:  'Помощь, поддержка…',  // объяснение в режиме «Пояснения»
  note:   'Словарь помечает: старинное…',   // необязательно
  source: 'А. Пушкин. Повесть «Капитанская дочка», 1836 г.',
  size:   0.92                   // можно уменьшить кегль (для прозы)
}
```

## Файлы

`index.html` — разметка; `styles.css` — темы и оформление; `data.js` — тексты
и объяснения; `app.js` — машинопись, подбор кегля, пояснения, темы;
`scene.js` — задний план (небо, светило, облака, птицы, дали, лес, поле),
рисуется под текущий размер окна. Библиотек нет, интернет не нужен.

## Про тексты

Отрывки сверены по академическим изданиям (Пушкин, Полное собрание
сочинений; тексты доступны на Викитеке). Два уточнения:

- Строфа с «брашна» входит в текст поэмы 1820 года (6‑я песня) и выпадает из
  некоторых позднейших редакций — если в вашем учебнике её нет, отрывок
  можно заменить.
- Во «Вадиме» строка дана как «**Пред ним** славянская дружина;» (так в
  раздаточном тексте урока). В ПСС 1937 (т. 4, с. 141, стих 102) та же строка
  читается «Перед ним…» — поправьте в `data.js`, если сверяетесь по
  «Подстрочнику».

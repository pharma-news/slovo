# «Слово» — игра у экрана по «Словарю языка Пушкина»

Весь экран поделён на **четыре части**. По очереди в каждой части появляется
текст — как будто печатает пишущая машинка (можно читать вслух синхронно с
экраном). **Непонятное слово выделено**: заглавные буквы, цвет, жирный,
пунктирное подчёркивание и лёгкое мерцание.

Ответы сразу **не показываются**. Дети ищут выделенные слова в
«Словаре языка Пушкина» — кто быстрее. Когда задание выполнено, пояснения
можно вывести на экран (сразу во всех четырёх — клавиша `E`, или по
отдельности — кнопкой `?` в углу нужной четверти). А можно и не выводить.

Ничего устанавливать не нужно: это папка с файлами, интернет не требуется.

## Как запустить

- двойной клик по файлу `index.html`, или
- открыть в браузере: https://pharma-news.github.io/slovo/

Дальше — `F` (или двойной клик мышью), чтобы выйти на весь экран.

| II | «Вадим», 1822 (неоконченная поэма) | **ловитва** — охота |

## Кнопки у каждой четверти

Внизу каждой четверти — две свои кнопки (поярче при наведении мыши):

- **`▶` слева внизу** — начать печать **этого** отрывка заново. Остальные три
  при этом остаются как были: можно ещё раз перечитать вслух только один
  отрывок, не сбрасывая весь экран.
- **`?` справа внизу** — показать (или спрятать) пояснение **только к этому
  слову**. Полезно, когда одна команда уже справилась, а остальные ещё ищут.
- Клик по самой четверти во время печати допечатывает её целиком — если вы
  читаете быстрее экрана.

## Управление

Нижняя панель с кнопками появляется, если подвести мышь (и прячется сама).
Клавиши работают всегда:

| Клавиша | Что делает |
|---------|-----------|
| `Пробел` | пауза / продолжить |
| `R` | все четыре отрывка заново |
| `V` | скорость: медленно · средне · быстро |
| `PageDown` или `→` | допечатать текущий отрывок целиком |
| `E` | пояснения сразу во всех четырёх (повторное нажатие — скрыть) |
| `C` | хронометр вверху справа — для соревнования «кто быстрее» |
| `T` | тема оформления |
| `F` или двойной клик | на весь экран |

## Темы

Три темы: **тёмная**, **белая**, **бежевая** («под старую бумагу»).
Переключаются кнопкой «Тема» внизу или клавишей `T`; выбор запоминается в
браузере. Кегль текста подбирается под размер окна автоматически: если
четверть маленькая, текст станет мельче, но в неё влезет; стихи не
переносятся — строка остаётся строкой.

## Как менять отрывки и слова

Всё в файле `data.js` — можно править в любом текстовом редакторе и
перезагрузить страницу. Слово‑загадка в тексте выделяется звёздочками:
`*СИКУРСУ*`. Поля у каждого отрывка:

```js
{
  text:   'строчки\nчерез \n',   // *звёздочками* — загаданное слово
  answer: 'сику́рс',              // словарная статья (для карточки)
  gloss:  'Помощь, поддержка…',  // объяснение в режиме «Пояснения»
  note:   'Словарь помечает: старинное…',   // необязательно
  source: 'А. Пушкин. Повесть «Капитанская дочка», 1836 г.',
  size:   0.92                   // можно уменьшить кегль (для прозы)
}
```

## Про тексты

Отрывки сверены по академическим изданиям (Пушкин, Полное собрание
сочинений; тексты доступны на Викитеке). Два уточнения:

- Строфа с «брашна» входит в текст поэмы 1820 года (6‑я песня) и выпадает из
  некоторых позднейших редакций — если в вашем учебнике её нет, отрывок
  можно заменить.
- Во «Вадиме» строка дана как «**Пред ним** славянская дружина;» (так в
  раздаточном тексте урока). В ПСС 1937 (т. 4, с. 141, стих 102) та же строка
  читается «Перед ним…» — поправьте в `data.js`, если сверяетесь по
  «Подстрочнику».

## Как это устроено

Один HTML, один CSS, два скрипта: `data.js` — тексты и объяснения,
`app.js` — машинопись, подсветка, пояснения, темы, хронометр. Библиотек нет,
интернет не нужен.

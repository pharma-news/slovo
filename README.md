# «Слово» — игра у экрана по «Словарю языка Пушкина»

Весь экран поделён на **четыре части**. По очереди в каждой части начинает
появляться текст — как будто печатает пишущая машинка (можно читать вслух
синхронно с экраном). **Непонятное слово выделено**: заглавные буквы, цвет,
жирный, пунктирное подчёркивание и лёгкое мерцание.

Ответы сразу **не показываются**. Дети ищут выделенные слова в
«Словаре языка Пушкина» — кто быстрее. Уже потом, когда задание выполнено,
на экран можно вывести пояснения (клавиша `E`) — а можно и не выводить.

Ничего устанавливать не нужно: это просто папка с файлами.

## Как запустить

- двойной клик по файлу `index.html`, или
- открыть в браузере адрес Pages: https://rodnikmay.github.io/slovo/

Дальше — `F` (или двойной клик мышью), чтобы выйти на весь экран, и
`Пробел`, чтобы ставить чтение на паузу.

## Управление

Панель с кнопками внизу появляется, если подвести мышь (и прячется сама).
Клавиши работают всегда:

| Клавиша | Что делает |
|---------|-----------|
| `Пробел` | пауза / продолжить |
| `R` | начать заново (сразу, без отсчёта) |
| `V` | скорость: медленно · средне · быстро |
| `PageDown` или `→` или клик по своей четверти | допечатать отрывок целиком, если вы опережаете экран |
| `E` | пояснения слов (кнопка становится доступна, когда напечатаны все четыре отрывка) |
| `C` | хронометр в правом верхнем углу — для соревнования «кто быстрее» |
| `F` или двойной клик | на весь экран |

## Как менять отрывки и слова

Всё в файле `data.js` — можно править в любом текстовом редакторе,
перезагрузив потом страницу. Слово‑загадка в тексте выделяется звёздочками:
`*СИКУРСУ*`. Поля у каждого отрывка:

```js
{
  text:   'строчки\nчерез \n',   // *звёздочками* — загаданное слово
  answer: 'сику́рс',              // словарная статья (для карточки)
  gloss:  'Помощь, поддержка…',  // объяснение в режиме «Пояснения»
  note:   'Словарь помечает: старинное…',   // необязательно
  source: 'А. Пушкин. Повесть «Капитанская дочка», 1836 г.',
  size:   0.92                   // можно уменьшить кегль (для прозы)
}
```

Кегль подбирается сам под размер окна: если четверть маленькая, текст
станет мельче, но в неё влезет; стихи не переносятся — строка остаётся
строкой.

## Тексты

Отрывки сверены по академическим изданиям (Пушкин, Полное собрание
сочинений; тексты доступны на Викитеке). Небольшое уточнение к первому:
строфа с «брашна» входит в текст поэмы 1820 года (6‑я песня) и выпадает из
некоторых позднейших редакций — если в вашем учебнике её нет, отрывок можно
заменить на другой, не меняя механики.

## Как это устроено

Один HTML, один CSS, два скрипта: `data.js` — тексты, `app.js` —
машинопись, подсветка, пояснения, хронометр. Библиотек нет, интернет не
нужен.
